# RAMZI AI — بوت البحوث المدرسية

## الخدمات
- إنشاء بحوث وملخصات وأسئلة مراجعة.
- استخراج النص من الصور وملفات PDF النصية وWord.
- تصدير المحتوى إلى Word وPDF.
- حد مجاني افتراضي: 5 طلبات يومياً لكل مستخدم.
- لوحة مسؤول عبر الأمر `/admin`.

## متطلبات التشغيل
Python 3.10 أو أحدث.

## المتغيرات السرية
أضفها في إعدادات الاستضافة (Environment Variables)، ولا تضعها داخل الكود:
- `BOT_TOKEN`: رمز البوت من BotFather.
- `OPENAI_API_KEY`: مفتاح OpenAI API.
- `ADMIN_ID`: رقم Telegram الرقمي الخاص بالمسؤول.
- `DAILY_LIMIT`: عدد الطلبات اليومية المجانية (افتراضي 5).
- `OPENAI_MODEL`: النموذج (افتراضي gpt-4o-mini).

## التشغيل المحلي
```bash
pip install -r requirements.txt
python bot.py
```

## النشر
- أنشئ Worker في Render أو خدمة تشغيل مستمرة تدعم Python.
- ارفع ملفات المشروع إلى GitHub.
- اجعل Build Command: `pip install -r requirements.txt`
- اجعل Start Command: `python bot.py`
- أضف المتغيرات السرية السابقة في Environment.
- لا ترفع `.env` أو مفاتيح API إلى GitHub.

## تنبيه مهم بخصوص PDF العربي
لأفضل إخراج عربي، أضف خط `DejaVuSans.ttf` داخل مجلد `fonts/` في المستودع.  
المسار المطلوب: `fonts/DejaVuSans.ttf`. إذا لم يوجد الخط، قد يتعذر إنشاء PDF العربي.  
ملفات Word تعمل دون هذه الخطوة.

## ملاحظات
- تخزين المستخدمين والعداد في `ramzi_data.json` محلي. على الاستضافات التي تمسح القرص عند إعادة التشغيل قد لا يبقى السجل؛ استخدم قرصاً دائماً أو قاعدة بيانات عند التوسع.
- PDF الممسوح ضوئياً: أرسل الصفحات كصور. استخراج النص من PDF يعتمد على وجود طبقة نصية.
- راجع البحث والمراجع قبل تسليمه للمدرس؛ المحتوى المولد يحتاج مراجعة بشرية.
